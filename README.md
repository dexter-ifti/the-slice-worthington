## Local web development

Requirements: Node.js 22+ and npm.

```bash
git clone https://github.com/dexter-ifti/the-slice-worthington.git
cd the-slice-worthington
npm ci
npm run dev
```

Open the local development server shown by Vite.

## Android development

Requirements: Android Studio, Android SDK, and a compatible JDK.

```bash
npm ci
npm run cap:sync
npm run cap:open:android
```

The Android project is located in `android/`. Build the debug APK in Android Studio or with:

```bash
cd android
./gradlew assembleDebug
```

The Android APK used by the README download link is generated by the `Android APK` GitHub Actions workflow.

## iOS Simulator build

The repository contains the shared Capacitor configuration and iOS build workflow. GitHub Actions generates the iOS project on a macOS runner, generates Slice icons and splash assets, builds an unsigned Simulator `.app`, and uploads it to Appetize.

The workflow can be started from:

```text
GitHub → Actions → iOS Simulator Preview → Run workflow
```

Required GitHub configuration for Appetize upload:

```text
Secret:   APPETIZE_API_TOKEN
Variable: APPETIZE_PUBLIC_KEY
```
